# 소개 영상 계획 — 나라장터 입찰공고 알림봇

## 개요

| 항목 | 값 |
| --- | --- |
| 도구 | Remotion 4 (React) |
| 규격 | 1920×1080, 30fps, 약 45초 (1350프레임) |
| 출력 | `video/out/intro.mp4` (H.264) |
| 소리 | 없음 (배경음은 라이선스 확인 후 따로 얹는다) |
| 톤 | 서비스 화면과 같은 차분한 업무용 톤 — 밝은 회색 배경, 짙은 회색 강조, 마감 임박은 주황(#b4491c), 정상은 초록(#0f7a5a) |
| 글꼴 | Noto Sans KR (본문), IBM Plex Mono (숫자·공고번호) |

## 핵심 메시지

> 수천 건의 공고를 매일 뒤지지 않아도, 내 키워드에 맞는 공고만 저녁 9시에 텔레그램으로 온다.

## 장면 구성

| # | 시간 | 장면 | 화면 | 자막 |
| --- | --- | --- | --- | --- |
| 1 | 0–6초 | **문제** | 공고 행들이 빠르게 흘러가고 카운터가 0 → 5,000+ 로 오른다 | "나라장터 입찰공고, 3일에만 5,000건 넘게 올라옵니다" |
| 2 | 6–10초 | **질문** | 흐르던 목록이 흐려지고 한 줄만 남음 | "우리 회사에 맞는 공고, 놓치고 있지 않나요?" |
| 3 | 10–15초 | **등장** | NJT 로고 마크 + 서비스 이름 + 한 줄 소개 | "나라장터 입찰공고 알림봇" |
| 4 | 15–24초 | **키워드 필터** | 서비스 화면 목업. 포함 키워드 칩(태양광·ESS·에너지저장)이 하나씩 붙고, 제외어(유지관리·청소)가 붙으면 목록이 5,214 → 12건으로 줄어든다 | "포함·제외 키워드로 필요한 공고만" |
| 5 | 24–34초 | **텔레그램 알림** | 시계 21:00 → 휴대폰 목업에 "🔔 새 공고" 메시지가 차례로 도착 (실제 `formatBundle` 형식) | "매일 저녁 9시, 텔레그램으로 도착" |
| 6 | 34–40초 | **기능 요약** | 카드 4장이 차례로 등장: 중복 방지 / 즐겨찾기 / 알림 이력 / 마감 D-day | "한 번 보낸 공고는 다시 보내지 않습니다" 등 |
| 7 | 40–45초 | **마무리** | 로고 + "키워드만 정하면, 공고가 찾아옵니다" | — |

장면 사이는 `@remotion/transitions` 의 fade / slide 로 잇는다 (전환 15프레임).

## 데이터

화면에 나오는 공고는 **예시 데이터**다. 실제 기관명·공고번호를 쓰지 않고 그럴듯한 가상 값을 쓴다
(예: "○○시 공공청사 태양광 발전설비 설치공사", 공고번호 `R26BK0000xxxx`).

## 파일 구조

```
video/
  PLAN.md               이 문서
  package.json          remotion, @remotion/cli, @remotion/transitions, @remotion/google-fonts
  remotion.config.ts
  src/
    index.ts            registerRoot
    Root.tsx            Composition 등록
    Intro.tsx           장면 이어붙이기 (TransitionSeries)
    theme.ts            색·글꼴 (public/styles.css 의 토큰을 옮김)
    data.ts             예시 공고
    scenes/
      Flood.tsx         1·2 문제/질문
      Logo.tsx          3 등장 · 7 마무리
      Filter.tsx        4 키워드 필터
      Telegram.tsx      5 텔레그램 알림
      Features.tsx      6 기능 요약
```

`video/` 는 배포 대상이 아니므로 `.vercelignore` 에 추가한다.

## 작업 순서

1. `video/` 에 Remotion 프로젝트 구성, 의존성 설치
2. 테마·예시 데이터 → 장면별 컴포넌트 작성
3. 장면 몇 프레임을 still 로 뽑아 레이아웃 확인
4. 전체 렌더 → `video/out/intro.mp4`

## 실행

```bash
cd video
npm install
npm run studio   # 미리보기 (브라우저)
npm run render   # out/intro.mp4
```
